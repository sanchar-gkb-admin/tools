Engine 2A — the exam day, offline end to end

One day. Two papers. Four self-report tests around them. One morning connection, and then the whole day runs from her phone — including every way it can go wrong.

Why 2A has its own storyboard. The 2C/2B journey is a set of sittings booked on a time grid, each sat online. 2A is a day: 09:45 to 16:15, both papers, with a pre-exam perception test and a post-exam reflection test around each one — 28 self-report questions, machine-scored into the same 15 abilities. It has a morning pack, a readiness check days ahead, a six-hour offline stretch, and refusals that exist only because there is nobody to ask.

Everything marked BUILT exists in code today (slices B–G, 20-Sep-2026) and the copy is the copy in the product, not a sketch. TARGET marks a screen that is specified but not finished.

Never "tasks". On screen they are the pre-exam perception test and the post-exam reflection test.

Task shuffling: what actually changes on screen

Each student gets their own task order, so answers can't be shared by task number. Most screens are unaffected. Three change, and one of those is a prerequisite rather than a nice-to-have — this is what each looks like before and after.

01 — MUST CHANGE

Scorecard · the per-task rows

Why. Today a card row says only “Task 3”. That works because everyone does the same tasks in the same order. The moment order is personal, “Task 3” on Anita’s card and “Task 3” on Ravi’s card are different tasks — and nothing on either card says so. A parent or an Acharya comparing two cards would be comparing unlike with unlike.

3Handle a difficult questionTask 3 of 2153.8
4Plan a week of studyTask 4 of 2157.6

The number is now “where it came in your journey”; the name says what it was.

Measured, not assumed. We ran the real scoring engine over the same tasks in four different orders, across 21-task and 7-task plans. Every total was identical — overall percentage, the four pillars, the band. Only the per-task rows move, which is the card correctly showing your own sequence. Shuffling cannot change anyone’s score.

Cost note for engineering: the card is produced by the scoring engine, and today we don’t send it the task name at all — the “1, 2, 3” is the engine numbering what it was handed. So this spans the app, the engine and the PDF template, and every frozen reference card will need re-approving.

02 — MUST CHANGE

Leaderboard · when a rank appears

Why. A rank shows up after the first evaluated task. With personal orders, Anita may have done tasks 1, 9 and 14 while Ravi has done 5, 2 and 20 — so a partial ranking compares them on different work. It’s also a gap today: a ₹999/₹1999 learner is told results unlock only when the whole set is evaluated, yet can read their rank here in the meantime. A rank is a measure.

Needs a decision: ₹4999 currently reveals progressively. Gating the rank on completion tightens that — a 21-task learner would see no rank for most of their journey. Consistent and fair, but it is a change in feel.

03 — SMALL ADDITION

Batch creation · the switch

Why. Shuffling is decided once, when a batch is created, and written into each student’s journey at that moment. It is never re-read afterwards — which is what guarantees no student already mid-programme is ever affected.

05

Still to decide

  • Does personal ordering make marking harder? An Acharya marking five students now sees five different sequences. It will be correct — their screen already follows each student’s order — but correct and convenient aren’t the same thing. Better to hear this now than after.
  • ₹4999 and the leaderboard. That tier reveals progressively today; gating rank on completion is a tightening.
  • Repeat enrolment. If someone enrols in the same programme twice, we’d give them a fresh order rather than the one they already saw.

Nothing changes for anyone already mid-programme: 62 students are currently in progress, and each one keeps the exact order they started with. Shuffling only ever applies to enrolments created after it’s switched on.

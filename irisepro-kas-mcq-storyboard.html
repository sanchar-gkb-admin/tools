KAS MCQ — the authoring admin

Six screens. The author's unit of work is a slot: a group of different questions sharing one topic, one cognitive demand, one ability set and one difficulty band.

This document is authoring only. The student experience moved to its own storyboard after a four-lens red team rewrote it. The evidence behind screens 01 and 09 is in the question × ability distribution map, parsed from the source papers and reconciled against their own summary tables.

The order is not a preference. Weights before questions, because the vector says what the slot must demand. English approved before translation, because a translator correcting an unreviewed source does the work twice. And a slot is not live until every language has passed — per-language release would quietly hand Kannada candidates a smaller pool, and the no-repeat guarantee is arithmetic over that pool.

10 · Quarantine — NEW

Quarantine stops a question being drawn. It does not decide what happens to the answers already given to it — and that is a measurement decision, not housekeeping.

Whichever is chosen is stamped on the card, like explanations_policy, for the same reason. Note attempts_included[] records which attempts fed a card but not which questions — so without questions_included[], options 1 and 2 are both unimplementable.
Cancel

Quarantine is not retire: papers already sitting keep the question, and nobody new draws it.

KAS MCQ — the authoring admin

Twelve screens. The author's unit of work is a slot: a group of different questions sharing one topic, one cognitive demand, one ability set and one difficulty band.

This document is authoring only. The student experience moved to its own storyboard after a four-lens red team rewrote it. The evidence behind screens 01 and 09 is in the question × ability distribution map, parsed from the source papers and reconciled against their own summary tables.
EXISTS — already in the codebase EXTENDS — existing thing, changed NEW — built for MCQ

Read this first

We are building a mock-test engine for KAS Prelims. A student buys a set, sits GS-1 and GS-2, and gets back not just a mark but a picture of how they think — which abilities the paper found strong and which it did not.

To do that honestly, no two students may sit the identical paper, and no student may meet the same fact twice across the eight sets they buy. So we do not write “one paper”. We write a bank, and each student’s paper is drawn from it.

KAS Prelims has 2 papers — GS-1 and GS-2. Together they are one set.
  Each paper has 100 questions. Question 22 is always the same kind of question — same subject, same difficulty, same skills. We call that position a slot.
    For each slot we write 9 different questions on different facts — 8 so a monthly student never repeats, plus 1 spare.
      Each question is then translated — English, Kannada, Hindi. Same question, different language.

That is 100 × 9 × 2 papers = 1,800 questions to write, and every one of them translated. The screens that follow are the tools for doing that without losing your place.

The order is not a preference. Weights before questions, because the vector says what the slot must demand. English approved before translation, because a translator correcting an unreviewed source does the work twice. And a slot is not live until every language has passed — per-language release would quietly hand Kannada candidates a smaller pool, and the no-repeat guarantee is arithmetic over that pool.

Words used on these screens

Everything else is ordinary English. If a screen uses a term that is not here, that is a bug in the screen.

SetOne sitting of both papers — GS-1 and GS-2 together. What a student buys.
SlotA position in the paper. Question 22 is always the same kind of question: same subject, same difficulty, same abilities.
QuestionOne actual question written for a slot. Nine per slot, each on a different fact.
VariantThe same question in another language. Not a different question.
ConceptThe fact a question tests. Two questions asking the same fact in different words share one concept, so a student is only ever given one of them.
DistractorA wrong option. Each one names the mistaken belief that makes it tempting.
WeightHow much a slot demands of one ability, out of 100. Every slot rates all 15.
DrawChoosing which of a slot’s 9 questions this particular student gets.
QuarantineTaking a question out of circulation because something is wrong with it.
GateAn automatic check that stops a question going live.

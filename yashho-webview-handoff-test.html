How to run it — 5 minutes

  1. Android: mail this page's URL to yourself, open Gmail, tap it. Expect IN-APP WEBVIEW. Tap "Open in your browser" → expect it to reopen in Chrome showing REAL BROWSER.
  2. iPhone with Chrome installed: same. The scheme only works if Chrome is present.
  3. iPhone WITHOUT Chrome: the button should fail harmlessly — confirm "Copy the link instead" still works. This is the case that must not strand anyone.
  4. Repeat in WhatsApp and Outlook if you have them — different webviews, different behaviour.
